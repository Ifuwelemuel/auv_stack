
# auv_stack

ROS 2 Humble software stack for a low-cost AUV investigating DVL-free learned
dead reckoning supervised only by sparse surface GPS fixes.

MSc dissertation project. Status: Phase 0 — bench bring-up.

## Hardware
- NVIDIA Jetson Orin Nano Super (companion computer, ROS 2 Humble)
- Pixhawk 2.4.8 running ArduSub (sensor hub, PWM output, failsafes)
- Blue Robotics T200 thruster, 2x 25 kg fin servos, syringe ballast via BTS7960
- Bar02 depth sensor, M8N GPS (surface buoy)
